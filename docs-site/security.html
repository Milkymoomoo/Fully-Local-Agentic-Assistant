Release notes

Verify a download yourself

Compare the SHA-256 of the file you downloaded with the one on its card above (and in the release's SHA256SUMS.txt). They must match exactly.

The APK is also signed. Its signing certificate's SHA-256 is 0e:5a:b9:71:bb:55:b0:ff:14:0d:ac:bc:cb:75:04:3e:ae:1f:88:3c:4e:ec:4c:2b:66:4f:fa:71:ea:6f:ed:8b; check it with apksigner verify --print-certs MilkyMoosAssistant-arm64-v8a.apk (Android SDK build-tools). Every update must carry the same certificate, or Android refuses to install it over the old one.

What the scans mean

ScanWhat it checksWhen
VirusTotalThe exact release file, checked by ~70 antivirus engines. "0 of N engines flag it" is the result to look for.Each release, rechecked weekly
CodeQLGitHub's code analysis of the Kotlin/Java and C/C++ source for security bugs.Every push, weekly
gitleaksThe whole git history for committed passwords, keys and tokens.Every push, weekly
OSV-ScannerDependencies and vendored libraries against the OSV database of known vulnerabilities.Every push, weekly
OpenSSF ScorecardHow the repository is run: branch protection, pinned actions, token permissions and more (0–10).Every push to main, weekly

Limits, honestly: no scanner proves software is safe. Antivirus engines can miss new threats and sometimes flag harmless apps (false positives), especially unusual ones like an app that bundles AI models. Read the full explanation in the security guide.
